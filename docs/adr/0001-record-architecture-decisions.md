# ADR-0001: Record architecture decisions

## Status
Accepted

## Context
The MVP plan calls for an explicit ADR process starting in Sprint 0.

## Decision
We record architecturally significant decisions as numbered Markdown ADRs
in `docs/adr/`. Every decision that changes a system boundary, a technology
choice, or a scope commitment gets one. ADRs are immutable once accepted;
superseding decisions get a new ADR that references the old one.

## Consequences
Decisions are traceable and reviewable at the Sprint 2/4/7/10 architecture
review points defined in the project plan.
